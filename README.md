# ⚡ NEON STUDY BOARD

موقع إدارة مهام دراسية بأسلوب Cyberpunk - خاص بطالب ثانوية عامة

## 🚀 كيفية الاستخدام

1. افتح ملف `index.html` في المتصفح
2. أضف مهامك من زر "+ مهمة جديدة"
3. اسحب المهام بين الأعمدة (مراكم → قيد التنفيذ → تم الإنجاز)

## 🎨 المميزات

- **3 طرق عرض**: Board (كروت) + List (قائمة) + Calendar (تقويم)
- **ألوان Neon** لكل مادة
- **شريط تقدم** لكل مادة
- **سحب وإفلات** سهل
- **تصميم متجاوب** للموبايل والكمبيوتر

## 🟣 الألوان

- **بنفسجي غامق**: الخلفية الأساسية
- **Neon Purple**: رياضيات
- **Neon Cyan**: فيزياء
- **Neon Green**: كيمياء
- **Neon Orange**: عربي
- **Neon Pink**: إنجليزي
